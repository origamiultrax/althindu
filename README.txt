ALT HINDU — landing page
========================

To run locally:
  Just open index.html in any modern browser.

To deploy on a static host (Netlify, Vercel, GitHub Pages, S3, etc.):
  Upload the entire folder. index.html is the entry point.

To swap in your real logo:
  Save your logo PNG as: assets/alt-hindu-logo.png
  (the page automatically picks it up; until then, an SVG fallback shows)

External assets (loaded over the network at runtime):
  - Background storm GIF: media.tenor.com
  - Side decoration GIFs: img1.picmix.com
  - Google Fonts (Cormorant Garamond, Inter, JetBrains Mono, Noto Serif Devanagari)

If any of those hosts break, the page degrades gracefully — fallbacks kick in.
